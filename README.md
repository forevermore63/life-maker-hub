# Life Maker Hub

Public production hub for **Sausage Therapy / Life Maker**:

- 10 micro-apps (InkLedger → RentRadar)
- Passive Shop with PayID / bank / Stripe
- Daily engine (productivity + cash tasks)
- Profit ledger (real sales only)

## Live

- Hub: https://life-maker-hub.vercel.app
- Cash shop: https://life-maker-cash-now.vercel.app

## Local

Open `index.html` or deploy the folder as a static site.

## Money path

1. PayID tab → save rails  
2. Shop → order  
3. Buyer pays  
4. Mark paid → deliver pack  
5. Cash in bank = withdraw
